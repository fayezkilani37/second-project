# 🎧 Pulse | Premium Wireless Audio

صفحة هبوط (Landing Page) لمنتج سماعات لاسلكية، مبنية بالكامل بـ **HTML** و **CSS** فقط، بدون أي مكتبات أو frameworks خارجية.

## 🔗 معاينة حية
شاهد الموقع مباشرة من هنا:
**[fayezkilani37.github.io/second-project](https://fayezkilani37.github.io/second-project/)**

## ✨ المميزات
- تصميم متجاوب (Responsive) يشتغل على الموبايل والتابلت وسطح المكتب، بأكتر من نقطة توقف (breakpoint)
- حركات وانتقالات سلسة (Transitions & Animations) على العناصر الأساسية
- قسم مميزات (Features) يعرض أبرز خصائص المنتج

## 🛠️ التقنيات المستخدمة
- HTML5
- CSS3 (Flexbox، Media Queries، Keyframe Animations)

## 📂 الملفات
| الملف | الوصف |
|---|---|
| `index.html` | هيكل الصفحة |
| `style.css` | كل التنسيقات والحركات والتصميم المتجاوب |
